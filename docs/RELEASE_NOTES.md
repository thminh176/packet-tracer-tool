# Packet Tracer Tool v0.1.0 — Initial Release

An independent, bilingual desktop companion for learning, inspecting, validating and troubleshooting Packet Tracer labs. Native offline Windows x86_64 Rust application; no Python required.

## Included

- Read-only modern PKA/PKT decoding and raw XML inspection.
- Recursive candidate checkpoints with explicit expected/current values, evidence and separate Passed, Failed and Unverified states.
- Supported IOS commands and endpoint GUI guidance, individual/device copy, CSV/Markdown/CLI export.
- Deduplicated IP/mask commands, grouped interface contexts and concise omitted-check summaries.
- English/Vietnamese JSON localization, saved preferences, background parsing and virtualized tables/XML.
- Bounded decoder and protected atomic report writes; third-party license notices in the ZIP.

## Installation

Download `packet-tracer-tool-v0.1.0-windows-x64.zip` and the matching `.sha256`, verify the checksum, extract the complete folder and run `pka-lab-inspector.exe`. The binary is unsigned. Generated scripts belong in Packet Tracer's target device CLI, never PowerShell.

## Compatibility limits

Successful decoding is not native grading parity. Assessment selection interpretation remains inferred; unlabelled network snapshots stay Unverified. Complex validators, custom/script graders, ambiguous enums and unsupported container versions remain limited. The known 32-checkpoint reference and real 126-checkpoint activity were not certified. Original synthetic fixtures are explicitly labeled. Reports and some diagnostics remain English. No private activity files, answers, Cisco binaries, logos or courseware are included.
